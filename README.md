# memory-cards
browser-based memory matching game with pokemon

made using html, css, and javascript.

players js flip cards to find matching pairs. earn exp, level up, unlock new boards, and more!


features:
- memory matching
- three different starting difficulties
- exp and levling
- timer and best time tracking
- multiple game boards
- move counter
- pause and resume
- unlockable pokedex
- multi color themes
- keyboard navigation supported :3
- automatic progress saving to local storage


how 2 play:
1. select difficulty
2. click card to reveal
3. find its matching pair
4. continue until all pairs have been matched
5. complete boards to earn more exp and level up!

controls:
- mouse: flips cards
- arrow keys: move between cards
- enter/space: flip
- pause: i don't need to explain this
- new board: restarting that current board
- restart: clear saved progress and return to main menu

notes:
- i used a free image uploading site so if a sprite isn't available anymore it'll just show a placeholder instead of crashing \o/
